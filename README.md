## Research Focus

I build and research systems at the intersection of **signal processing** and **statistical machine learning** — with emphasis on low-latency architectures, physiological and time-series signal extraction, and edge-deployable inference pipelines.

Current work centers on: adaptive filtering for non-stationary signals, learned feature representations from raw sensor streams, and real-time inference under strict latency and resource budgets.
